# Alternance Scraper

Agrégateur automatique d'offres d'alternance pour profil ESSEC BBA 3e année.

## Sources

- **Welcome to the Jungle** (API Algolia)
- **La Bonne Alternance** (API beta.gouv.fr)
- **1jeune1solution / France Travail** (API OAuth2, optionnel)
- **ATS Hub** : SmartRecruiters, Greenhouse, Lever

## Déploiement rapide

1. Fork ce repo
2. Configurez les [GitHub Secrets](setup_guide.md#6-configurer-les-github-secrets)
3. Le scraper tourne automatiquement chaque matin à 10h (heure de Paris)

Consultez le [guide de setup complet](setup_guide.md) pour les instructions détaillées.
